# 季度规划工作流

## 目标

把外部市场、内部业绩和执行能力连接起来，形成少量明确战略选择、可衡量的季度重点和需要验证的商业假设。

战略不是框架的集合。完成本 Skill 后，团队应能回答：服务谁、解决什么问题、为什么现在做、做什么、不做什么、如何赚钱、如何衡量成功。

## 适用场景

- 季度或半年规划。
- 进入新市场、新产品或新客户群。
- 增长停滞、利润恶化或竞争格局变化。
- 重新评估商业模式、定价、渠道或资源投入。

单纯整理行业新闻、生成 SWOT 或制作战略模板时，不要只用框架填充内容。

## 必需输入

- 上一周期的目标、结果、偏差和复盘。
- 收入、成本、毛利、留存、获客和转化数据。
- 客户细分、购买原因、流失原因和 Win/Loss 证据。
- 市场、竞品、渠道、政策和替代方案变化。
- 团队能力、预算、技术、合规和时间约束。

缺少数据时，明确标为估算或假设，并安排验证动作。

## 工作流

### 1. 建立经营基线

先回答：

- 上季度承诺了什么，实际发生了什么？
- 偏差来自市场、执行、产品、定价还是资源？
- 哪些结果可重复，哪些只是偶发？
- 当前最重要的限制条件是什么？

不要用“市场不好”或“执行不到位”结束分析。把原因拆成可验证的业务机制。

### 2. 扫描外部环境

只保留会改变战略选择的信息。可组合以下框架进行分析，但输出必须是结论，不是框架说明：

- SWOT：内部能力与外部机会威胁。
- PESTLE：政策、经济、社会、技术、法律和环境变化。
- 波特五力：行业利润和竞争压力。
- Ansoff：市场与产品组合的增长选择。
- 竞品分析：定位、价格、渠道、客户和产品动态。

每个关键变化都要说明：影响哪个客户、哪种收入、哪条渠道、什么时间窗口，以及团队能做什么。

### 3. 明确战略选择

战略必须包含取舍：

- 目标客户群。
- 优先解决的问题和 Jobs-to-be-Done。
- 价值主张和为什么客户选择我们。
- 选择进入或放弃的市场、场景和渠道。
- 为取胜必须建立的差异化能力。
- 明确不做的机会。
- 竞争对手无法或不愿复制的部分。

如果所有客户都重要、所有功能都要做、所有渠道都要尝试，说明战略还没有形成。

### 4. 检查商业模式与经济性

将战略转换为可检验的经济模型：

- 收入来源和计费方式。
- 成本结构、毛利和规模效应。
- 获客成本、转化、留存和回收期。
- 定价锚点、客户支付意愿和替代成本。
- 增长依赖的飞轮或渠道是否可持续。

不要只给一个价格点。说明价格对象、套餐结构、价值计量单位、可能的反应和验证方式。

### 5. 反方验证

在做季度承诺前，对战略进行压力测试：

- 最关键的承重假设是什么？
- 什么证据会证明方向错误？
- 最便宜的验证方法是什么？
- 哪个错误会危及收入、用户信任、合规或团队生存？
- 如果主要假设失败，Plan B 是什么？

明确 Kill Criteria。没有停止条件，就没有真正的实验。

### 6. 形成季度重点

把规划收敛为最多三个战略赌注。每个赌注包含：

- 要改变的业务结果。
- 为什么这是当前最高杠杆点。
- 负责人。
- 主要动作和依赖。
- 领先指标与结果指标。
- 验证时间点。
- 停止、扩大或转向条件。

其他工作归入“维持运营”或“暂缓”，不要挤占战略资源。

## 输出格式

默认输出一份中文季度规划简报，包含：

1. 上季度基线与偏差。
2. 外部环境关键变化。
3. 战略选择和不做清单。
4. 商业模式与定价假设。
5. 三个季度重点赌注。
6. 指标树与验证计划。
7. 风险登记表与 Kill Criteria。
8. 未来 30、60、90 天行动。

## 质量门槛

- 不把框架清单当作战略结论。
- 不承诺超过三个战略重点。
- 不设置没有所有者、指标和时间边界的计划。
- 不在没有支付意愿证据时确定价格。
- 不用市场份额或市场规模估算掩盖未知。
- 每个战略赌注都必须有反方证据和停止条件。

## 与 pm-skills 的映射

如果环境中安装了 `pm-skills`，可以参考：

- `/market-scan`：宏观、竞争和增长组合扫描。
- `/strategy`：九段 Product Strategy Canvas。
- `/business-model`：Lean Canvas、Business Model Canvas 或 Startup Canvas。
- `/pricing`：定价模型、支付意愿和实验。
- `/red-team-prd`：攻击战略和计划的承重假设。
- `/plan-okrs`：将战略重点转成团队 OKR。

命令生成的是输入材料，最终必须落到选择、取舍、指标和停止条件。
